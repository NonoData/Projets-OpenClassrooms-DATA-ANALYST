# 📊 Portfolio 

Les différents tableaux de bord réalisés avec Power BI ont été créés pour répondre à la demande de réalisation d'un portfolio comprenant mon profil, une veille technologique et un diagramme de Gantt.

Les différents documents sont utilisés pour la page suivante : [**Livrable**](https://nonodata.github.io/)

Ce projet a pour but de vous permettre de rédiger un portfolio en ligne personnalisé.
